## Overview

**Nebula Connected** is a production-grade, enterprise-ready vehicle telemetry and command platform engineered for next-generation electric hypercars. Built on **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS v4**, this application demonstrates a mission-critical automotive digital cockpit and remote management dashboard with zero external font latency and real-time interactive telemetry.

---

## Architectural Highlights

- **Pure SVG Iconography:** 100% vector icons powered by `lucide-react` with uniform `viewBox`, accessible labeling, and dynamic theme adaptation.
- **Studio-Lit Automotive Visuals:** Ultra-high-resolution 4K automotive showroom assets generated via Gemini generative image synthesis, showcasing both studio profile and dynamic front three-quarter perspectives.
- **Live TPMS & Chassis Diagnostics:** Active 4-corner tire pressure and thermal mesh monitor with on-demand auto-balancing and calibration.
- **Dynamic Torque & Vectoring HUD:** Real-time powertrain distribution simulation across dual front and rear axles with selectable drive profiles (`SPORT`, `TRACK`, `ENDURANCE`).
- **CAN-Bus Terminal Diagnostics:** Encrypted streaming system log console with interactive pause/resume and live buffer clearance.
- **Tactical Navigation HUD:** Vector-based dynamic route planner with animated HUD paths, waypoint search, and arrival battery prediction.
- **Student Identity & Attribution:** Seamless global integration of student attribution across document metadata, header badges, driver profile configurator, interactive credits modal, and global footer.

## Getting Started

### Prerequisites

- Node.js 20.x or higher
- npm, pnpm, or yarn

### Installation

```bash
npm install
```

### Development Server

Run the development server locally:

```bash
npm run dev
```

Navigate to [http://localhost:3000](http://localhost:3000) to view the live dashboard.

### Production Build & Verification

```bash
npm run build
```
